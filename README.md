# Nirbhay Shingala — Portfolio

Personal portfolio site. Plain HTML, CSS and JavaScript — no build step.

**Live:** [nirbhay-shingala.vercel.app](https://nirbhay-shingala.vercel.app)

Deployed on Vercel; every push to `main` goes live automatically.

Run locally:

```bash
python -m http.server 5500
```

Then open http://localhost:5500.
